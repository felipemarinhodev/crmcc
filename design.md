# Identidade visual do CRM

Estas regras valem para **todas** as telas do projeto.

## Clima

Ferramenta profissional, limpa e confiante. Um produto, não um template.

## Cores

| Uso | Cor |
| --- | --- |
| Fundo da página (claro, levemente quente) | `#FAFAF7` |
| Superfícies (cartões, painéis) | `#FFFFFF` |
| Borda sutil | `#E6E4DE` |
| Texto principal (grafite) | `#17181C` |
| Texto de apoio | `#6B6E76` |
| Destaque: ações e elementos ativos (azul-cobalto) | `#1D4ED8` |
| Destaque no hover (mais escuro) | `#1E40AF` |

O azul-cobalto é a **única** cor de destaque. Nenhuma outra cor de marca.

### Etapas do funil

Usadas **só** nas etiquetas de etapa.

| Etapa | Cor |
| --- | --- |
| Novo | `#64748B` |
| Em contato | `#D97706` |
| Proposta | `#7C3AED` |
| Cliente | `#15803D` |

## Tipografia

- Fonte "Manrope" (Google Fonts) em tudo.
- Títulos em peso forte, textos em peso normal.
- Tamanhos generosos e hierarquia clara.

## Formas

- Cantos levemente arredondados: `10px`.
- Bordas visíveis em vez de sombras pesadas.
- Bastante respiro entre os elementos.

## Proibido

- Gradientes.
- Efeito de vidro/desfoque.
- Emojis na interface.
- Sombras exageradas.
- Animações chamativas.

Se parecer template de IA, está errado.
